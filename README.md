# Gravity AR Lab

เว็บต้นแบบสำหรับทดลองปล่อยวัตถุด้วยกล้องมือถือ

## การสรุปผล
- นักเรียนกด **เริ่มตรวจจับ** เพื่อเริ่มการทดลอง 1 รอบ
- เมื่อวัตถุถูกตรวจพบและเริ่มตก ระบบเก็บข้อมูลการเคลื่อนที่ภายใน
- นักเรียนกด **หยุด** เมื่อจบการทดลอง
- ระบบสรุป **1 รายการต่อ 1 รอบ** และบันทึกลงประวัติอัตโนมัติ
- ตารางจะแสดงเฉพาะ วัตถุ / เวลาตก / ระยะทาง / ความเร็วสูงสุด
- ข้อมูลทุกเฟรมยังเก็บไว้ภายในรอบนั้นเพื่อใช้สร้างกราฟ แต่ไม่แสดงเป็นหลายรายการ
